# Pong Kombat 🔥🚀

¡El clásico juego de "Pong", pero transformado en una batalla épica de reflejos, estrategia y mecánicas celestiales!

## 🔭 ¿Qué hay de nuevo en la v0.3.3?
¡La versión más completa y pulida!
*   **Planetas Flotantes:** Dos astros con gravedad física que curvan la trayectoria de la pelota. ¡Cuidado con su atracción!
*   **Identidad Planetaria:** Astros con nombres reales (Tierra, Marte, Júpiter, Saturno) y explosiones temáticas.
*   **Multiplicador X2:** Captura el ícono dorado para que tu próximo gol valga doble.
*   **Sistema de Skins:** Personaliza tus poderes (Hadouken) y relojes (¡Skin de **Cruz Bíblica**!).
*   **Control de Velocidad:** Modificadores para velocidad inicial (modo FLASH) e incremento por rebote.
*   **Audio Pro:** Optimización para eliminar crujidos de sonido en Windows.

##  Cómo instalar y jugar
1. Necesitas tener Python instalado (recomendamos la versión 3.12).
2. Abre tu terminal e instala la librería:
   ```bash
   python -m pip install pygame-ce
   ```
3. Inicia el juego:
   ```bash
   python3.12 main.py
   ```

## 🎮 Controles 🕹️
*   **Jugador 1 (Izquierda):** Movimiento `W/S`. Poder `D`.
*   **Jugador 2 (Derecha):** Movimiento `Flechas`. Poder `Flecha Derecha`.
*   **Navegación:** Usa el **Mouse** para los menús y modificadores.

## 🛡️ Mecánicas Kombat 🔥
*   **Poderes:** Bola de Fuego, Escudo Gigante, Velocista, Bola de Demolición e Imán.
*   **Relojes de Arena:** Cámara lenta, Aceleración, Carga rápida, Barrera Divina y Muro Absoluto.
*   **Modificadores:** Personaliza el límite de puntos, la frecuencia de aparición y mucho más.
